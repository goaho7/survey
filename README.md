# Survey

Система пользовательских опросов.

## Запуск

```bash
poetry install
poetry run python manage.py makemigrations surveys
poetry run python manage.py migrate
poetry run python manage.py runserver
```

## Сделано

- Ввиду ограничения по времени на задачу (30–40 минут) основной упор сделал на реализацию схемы моделей: опрос, версии опроса, вопросы и варианты с порядком, вариант «Свой ответ», прохождения, ответы, статистика.
- Опубликованная версия не редактируется.
  Логику версий взял из своего последнего проекта, где была схожая реализация.
- `GET /api/surveys/<id>/next-question/` - следующий вопрос для пользователя
  с учётом прогресса.
